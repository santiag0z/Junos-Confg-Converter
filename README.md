# Junos OS Confg Converter

A fast, clean, and modern web-based tool to convert native Junos OS configurations into SET, JSON, or XML formats.

![Junos Converter Preview](https://img.shields.io/badge/status-active-success.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

## ✨ Features

- **Multi-format Conversion:** Transform raw Junos configurations into `SET`, `JSON`, or `XML` outputs.
- **Drag & Drop Support:** Easily upload configuration files (`.txt`, `.conf`, `.json`).
- **One-Click Actions:** Quickly copy outputs to your clipboard or download them as files.
